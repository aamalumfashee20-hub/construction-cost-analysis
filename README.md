Construction Cost Analysis Using Python

Author: Aliyu Yahuza Aliyu  
Project Type: Independent Data Analytics Portfolio Project  
Focus Areas:Data Analysis, Construction Cost Monitoring, Data Quality Assurance and AI-Assisted Review

1. Project Overview

This project demonstrates how Python can be used to analyse construction project costs, compare budgeted and actual expenditure, identify cost variances and support data quality reviews.

It uses an illustrative construction Bill of Quantities (BOQ) dataset to demonstrate practical data analytics techniques in a quantity surveying and project management environment.

2. Project Objectives

- Analyse construction BOQ cost data using Python.
- Compare budgeted costs against actual expenditure.
- Identify items with significant cost overruns.
- Summarise cost performance across project sections.
- Detect potential data quality issues.
- Present findings through charts and structured reports.

5. Key Findings

The illustrative dataset contains 35 construction BOQ items.

| Metric | Result |
|---|---:|
| Total Budget | ₦143,072,100 |
| Total Actual Cost | ₦155,978,700 |
| Net Cost Variance | ₦12,906,600 |
| Percentage Variance | 9.02% |
| Items Over Budget | 34 |
| Items Under Budget | 1 |

The analysis indicates that actual expenditure exceeded the overall budget by approximately 9.02%.

6. Data Quality Assurance

A separate test dataset was prepared with intentionally introduced data-quality issues.

The quality review demonstrates how potential problems can be identified before using project data for reporting and decision-making.

This includes reviewing records for missing information, inconsistent values, duplicate entries and other potential anomalies.

7. AI-Assisted Review Application

The project also demonstrates a workflow that could be enhanced with AI-assisted data review.

Potential applications include:

- Identifying unusual cost entries.
- Flagging inconsistent BOQ descriptions.
- Supporting automated document checks.
- Highlighting possible cost anomalies.
- Improving the accuracy and consistency of project reports.

AI-assisted review is presented as a potential application, not as an implemented or independently validated AI model.
